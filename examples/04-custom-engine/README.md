# 04 - write your own engine

`reverse_engine.cpp` is a complete engine plugin (it reverses the text it gets); `host.cpp` loads it through the engine host
process and runs a request. Walkthrough: [writing an engine](../../docs/guides/writing-an-engine.md). To start a plugin outside
this tree, copy [08-engine-plugin-template](../08-engine-plugin-template).
